

# F18 — Documentos + Manual + Inventarios

## Objetivo

Crear el único sistema documental genérico privado V1 para property/lease, manual de convivencia e inventarios inicial/final.

## Arquitectura

```text
NEW_TABLES: 1 documents
NEW_DOMAIN_CLASSES: 1 DocumentService
NEW_ROUTE_FILES: <=1
NEW_PERMISSIONS: 2 documents.view/documents.manage
NEW_PUBLIC_ROUTES: 0
NEW_RUNTIME_DEPENDENCIES: 0
NEW_DOCUMENT_TYPE/INVENTORY/VERSION_TABLES: 0
```

Modelo:

```text
id
property_id nullable
lease_id nullable
type
title
content_json nullable
stored_name nullable
mime_type nullable
sha256 nullable
size_bytes nullable
supersedes_document_id nullable
created_by_user_id
created_at
```

Exactamente un scope primario: `property_id XOR lease_id`.

Tipos iniciales:

```text
property_document
lease_document
manual_convivencia
inventory_initial
inventory_final
other
```

Filas inmutables; nueva versión = nueva fila con `supersedes_document_id`. No version-history table.

Archivos privados PNG/JPEG/WebP/PDF <=10 MiB, MIME por bytes, nombre aleatorio, hash/tamaño exactos.

Inventario en `content_json` snapshot simple con `general_notes` + items `{area,item,condition,quantity?,notes?}`. No inventory-items table V1. Comparación inicial/final derivada. No cargo automático; F14/F9 siguen siendo autoridades.

Manual convivencia = document property-scoped versionado; no tabla paralela.

No migrar retrospectivamente soportes F4–F17 salvo necesidad demostrada.
