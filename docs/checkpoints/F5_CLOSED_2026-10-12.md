## 3. Modelo y flujo final

F5 es candidate-centric: `candidates` representa la persona y su único proceso activo F5, con una sola `unit_id` actual.

Identidad única normalizada:

```text
UNIQUE(document_type, document_number)
```

Duplicado público:
- no crea segunda fila;
- no devuelve/regenera token;
- no expone nombre, correo, unidad, estado ni candidate ID;
- usa respuesta genérica + throttle;
- F5 no afirma ocultación fuerte de existencia sin canal fuera de banda.

Token de continuación:

```text
raw = bin2hex(random_bytes(32))
DB = hash('sha256', raw)
TTL = 604800 seconds
```

- raw nunca se persiste;
- expirado/malformado falla cerrado;
- rotación invalida inmediatamente el anterior;
- raw regenerado solo aparece en la respuesta administrativa inmediata;
- error logs redactan `/apply/continue/{64hex}` como `/apply/continue/[redacted]`.

Estados F5 exactos:

```text
new -> incomplete | verification | withdrawn
incomplete -> verification | withdrawn
verification -> pending_screening | withdrawn
pending_screening -> withdrawn
withdrawn -> terminal en F5
```

`new|incomplete -> verification` solo ocurre mediante `submitByToken()` tras validación de completitud; administración no puede simular submit.

Reglas:

- URLs públicas no contienen candidate/document IDs internos;
- POST reutiliza CSRF global;
- basePath/subfolder preservado;
- throttle V1 session-local: start 5/10 min; continue mutations 10/10 min; 429 no muta.

## 5. Requisitos y documentos privados

`units.requirements` permanece texto comercial público F4. `unit_application_requirements` es la fuente estructurada operacional F5.

Requirement code:

```text
[A-Za-z0-9_-]+
max 80
unique per unit
immutable
```

No existe delete físico de requirement; se inactiva.

Documentos candidatos:
- PDF/JPEG/PNG por MIME real;
- máximo 10 MiB;
- nombre almacenado generado;
- storage privado fuera del webroot;
- uno vigente por `(candidate_id, requirement_id)`;
- reemplazo seguro;
- ownership candidate+document anti-IDOR;
- `privateDocument()` revalida existencia física, MIME y tamaño;
- path traversal/fake MIME/tampering fallan cerrado;
- descarga admin: persisted MIME + `X-Content-Type-Options: nosniff` + `Cache-Control: private, no-store`;
- submit exige todos los requisitos current required+active físicamente válidos.
