## 3. RED → GREEN RELEVANTE

### Base URL

RED: clase ausente.  
GREEN: `BaseUrlDetector` simple, sin proxy abstraction.

### Runtime

RED: faltaba gate PHP/extensiones/storage.  
GREEN: `RuntimeRequirements`, una sola evaluación explícita.

### Base de datos

RED: faltaban configuración y conexión.  
GREEN: `DatabaseConfig` + `DatabaseConnector`, PDO directo, sin ORM.

### Migraciones

RED: faltaba aplicación/idempotencia.  
GREEN: un `MigrationRunner`; `schema_migrations` es infraestructura interna del runner, no una migración que dependa de sí misma.

### Lock

RED: faltaba bloqueo post-instalación.  
GREEN: existencia de un único archivo = instalado; contenido corrupto falla cerrado.

### Instalación

RED: propietario/config/lock y reintento no existían.  
GREEN: `Installer` retry-safe; lock escrito al final.

### Web installer

RED: 24 pruebas previas PASS + 5 fallos esperados por ausencia del bootstrap web.  
GREEN: callable factory Slim + una vista + un entrypoint + rewrite Apache.

### Seguridad

RED: 29 pruebas previas PASS + 2 fallos específicos: excepción filtraba secreto y rutas internas no estaban bloqueadas.  
GREEN: error boundary sanitizado + una sola regla Apache convergente.

### Instalación limpia

RED: 31/32 PASS; `storage` inexistente deshabilitaba incorrectamente el instalador.  
GREEN: se comprueba el ancestro existente escribible sin crear carpetas durante GET.
